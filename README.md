# Outbid

Silent auctions run by students. Local businesses donate, students make them famous, charities get every dollar.

- Build plan: [`BUILD_PLAN.md`](BUILD_PLAN.md)
- Status: [`PROGRESS.md`](PROGRESS.md)
- Mockups: `design/screens/`

## Run it

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:3000/dev/components.

```bash
npm test
```
